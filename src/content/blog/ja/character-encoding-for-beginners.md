## コンピューターは文字ではなく数字を保存する

コンピューターの最も基本的な情報は `0` と `1` です。文字を保存するには、「この数字はどの文字か」と「その数字をどう byte にするか」の約束が必要です。

| 用語 | かんたんな意味 |
| --- | --- |
| 文字集合 | 文字と番号の対応表 |
| エンコーディング | 番号を byte として保存する方法 |

日常では UTF-8 を「文字コード」と呼ぶことが多いですが、厳密には Unicode の文字を保存するエンコーディングです。

## ASCII、GBK、Unicode

ASCII は英字、数字、記号のために作られた方式で、中国語や日本語、emoji は表現できません。

GBK は簡体字中国語を扱うために広く使われた文字コードです。古い Windows ソフトや古い中国語のテキストで見かけますが、多言語や emoji を扱う新しいプロジェクトには向いていません。

Unicode は世界中の文字に共通の番号を割り当てる仕組みです。

```text
U+0041  A
U+4F60  你
U+597D  好
```

UTF-8 は、この Unicode の番号をファイルに保存する代表的な方法です。

## なぜ UTF-8 を選ぶのか

UTF-8 は多くの言語と emoji を表せて、ASCII とも互換性があり、Web、コード、GitHub、API で標準的に使われています。

| 内容 | UTF-8 の一般的なサイズ |
| --- | --- |
| 英数字 | 1 byte |
| 一般的な中国語 | 3 bytes |
| 多くの emoji | 4 bytes |

新しいコード、Markdown、HTML、JSON、YAML、CSV は、特別な指定がない限り UTF-8 を選びましょう。

## 文字化けの仕組み

典型的な原因は保存時と読み込み時の不一致です。

```text
UTF-8 で保存 → GBK として開く
GBK で保存 → UTF-8 として開く
```

同じ bytes を別の対応表で読んでしまうため、文字化けが起きます。四角や `?` は、文字を表示するフォントがない場合にも起こります。

VS Code で文字化けしたら、右下の encoding 表示をクリックし、**Reopen with Encoding** で UTF-8 や GBK を試してください。正しく表示されたら UTF-8 で保存します。文字化けした状態で何度も上書き保存する前に、必ずバックアップを取りましょう。

覚え方は一つです：**新しいファイルは UTF-8、古い中国語ファイルは GBK も疑い、保存時と読み込み時の文字コードを合わせる。**
